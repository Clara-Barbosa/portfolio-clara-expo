# 📱 Portfólio Pessoal — Maria Clara

Aplicativo de portfólio pessoal desenvolvido em **React Native + Expo** para a disciplina de Programação Web Mobile.

O projeto apresenta informações sobre minha formação, experiências, conhecimentos e projetos desenvolvidos durante minha trajetória acadêmica em Ciência da Computação.

## 👩‍💻 Sobre o aplicativo

O portfólio possui diferentes telas acessadas através do **Expo Router**:

- Home
- Sobre Mim
- Experiência Acadêmica
- Experiência Profissional
- Projetos
- Jogo da Forca

## 🎮 Jogo da Forca

O aplicativo também possui um **Jogo da Forca desenvolvido diretamente em React Native**.

O jogador deve descobrir palavras relacionadas a comidas e pratos antes de atingir o limite máximo de erros.

O jogo funciona dentro do próprio aplicativo, sem utilização de WebView ou redirecionamento para uma aplicação web.

## 📚 Objetivo

O objetivo do projeto é adaptar meu portfólio anteriormente desenvolvido para web para uma aplicação mobile utilizando React Native e Expo, aplicando conceitos de desenvolvimento mobile, componentização, navegação entre telas e gerenciamento de estado.
